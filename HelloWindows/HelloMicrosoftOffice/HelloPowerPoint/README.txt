Microsoft PowerPoint
  A Presentation making program, that at its simplest makes an array of slides that are easy to show on screens.
  
  On Launch: Home screen
    On the left vertical panel
      Home (default)
      New presentation, shows more templates and themes
      Open presentation
      
    Main screen
      New presentation with theme choices
      Search for a presentation to open
      Recent, Pinned, Shared With Me
      
  Common Hotkeys
    Copy: Ctrl+C
    Cut: Ctrl+X
    Paste: Ctr+V
  
  The Layout
    Top Border
      Autosave
      Save (Ctrl+S)
      Undo (Ctrl+Z)
      Redo (Ctrl+Y)
      Present (F5)
      Presentation options
      Name of Presentation (default Presentation1)
      Search for in built functions (ALT+Q)
      
    Tabs and Ribbons
      Each tab displays a ribbon with related groups of options
      
      Home (default)
        New Slide, Slide format
        Fonts
        Add-ins: external options made with code
      
      Insert
        Pictures
        Text boxes
        
      Draw
        Create pencil-like linesd
      
      Design
        Choose themes and variants, change font and backgrounds
        Browse for additional themes or make your own
        Designer* - Advanced
          Looks at slide content and recommends theme.  Be careful.
        
      Transitions
        Change how the slide changes into the next
        Effect Options provides ways to transition, don't overdo it.
        
      Animations
        Things that move for the current slide
        
      Slide Show
        Options on starting the presentation
        
      Record
        Recording options for the presentation
        
      Review
        Editing tools that work well with collobaration
      
      View
        Visual display of the current presentation, often used in tandem with review
        
      Help
        Help options like information or contacting support
          
    Common Useful actions
      New Slide Ctrl+M
      Slide Layout Alt+H, L
      Theme Alt+G, H
