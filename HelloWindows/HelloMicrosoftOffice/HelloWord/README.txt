Microsoft Word
  A text editing/processing program.  
  Previous versions were free, eventually it was a one time buy, and currently it costs a subscribtion.
  
  Usage
    Upon opening the program you may be greated with tabs on the left.
      Home Tab: 
      New Tab: Begins the creation of a new Word Document, with options to choose from templates
      Open Tab: Opens a file
      Accounts: Allows you to choose which Microsoft account, licenses for Word/Offic, OneDrive (Microsoft cloud storage), Add-ins, updates, and Microsoft Office background and themes.
    
    Misc Hotkeys:
      Save as: Ctrl+Shift+S
      Select All: Ctrl+A
      Undo: Ctrl+Z
      Redo: Ctrl+Y
      Copy: Ctrl+C
      Cut: Ctrl+X
      Paste: Ctrl+V
      Hyperlink: select text, Ctrl+K
      
    The Layout
      Window Bar - at the tippy top
        Autosave: Click to enable/disable
        Save (Ctrl+S):  
        New Document (Ctrl+N):
        Open (Ctrl+O):
        Find (Ctrl+F):
        "Document Name" (default Document1) - Word
        Search (ALt+Q): Search for Word function (ex: ruler, insert symbol), makes it faster than clicking tabs 
      
      Tabs - across the top
        Each tab you click yields a different Ribbon that provides related function groups
        Groups often have a Launch button in their lower right corner to provide more options
        
        File
          Brings you to the previous "on open Word" page
        
        Home
          Default tab, most common tools found here
          Font: type, size, modifiers
            Bold (Ctrl+B): Begins bold or bolds selected text
            Italics (Ctrl+I): Begins italics or italicizes selected text
            Underline (Ctrl+U): 
          Paragraph: spacing, bullets
          Syles
          Editing: Find Replace Select
          Add-ins: Solutions that extend the functionality of Word, extremely useful for certain tasks
          
        Insert
          Second most common Ribbon you'll likely use
          Notable: Symbols and Pictures
          
        Draw
          Yields options to draw as with a pen or pencil on the document
          
        Design
          Themes, colors, fonts, and watermarks
          
        Layout
          Margin, Orientaiton, Size, notably Columns
        
        References
          Notably insert citation, auto-gen Bibliography/Works Cited, and source manager
          
        Mailings
          Preparation for email or manual 
        
        Review
          Temporary editing and notes with logging that can be accepted or denied, often for collaboration
          
        View
          Visual display of the current document, generally doesn't edit the document itself
          
        Developer*
          If it's not there by default
            Open options (ALT+F, T) -> Customize the Ribbon -> Check the Developer tab
          Advanced
          Most common usage is Controls for fillable forms
          Macros, create shortcuts for (series of) actions
          Visual Basic, typically making triggers that do things when a user makes an event
          
        Help
          Provides information about Word
